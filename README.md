## 💻 Sobre o conteúdo

Realizada no início de 2025 durante uma Code Talk da [CodeBrain](https://codebrain.com.br/), a apresentação explora diferentes níveis de uso do Obsidian, desde uma abordagem mais simples, para quem busca apenas um espaço para planejamento e anotações, até uma utilização mais avançada, com automações e integrações.

O repositório reúne todo o material apresentado, incluindo:

- Slides da apresentação (feitos no próprio Obsidian)
- [Gravação da apresentação](./Apresentação/)
- Exemplos práticos organizados por nível:
  - [Nível 1](./Nível%201/)
  - [Nível 2](./Nível%202/)
  - [Nível 3](./Nível%203/)
  - [Nível 4](./Nível%204/)
- [Documentação extra](./Extras/) para utilização do tema [AnuPpuccin](https://github.com/AnubisNekhet/AnuPpuccin)

Os exemplos foram desenvolvidos especificamente para a apresentação e permanecem disponíveis como material de referência.

## 🚀 Como utilizar

Para explorar os exemplos práticos:

1. Clone este repositório: `git clone git@github.com:f-ernanda/obsidian-ftw.git`
2. Abra o [Obsidian](https://obsidian.md/) e selecione "Open folder as vault"
3. Selecione a pasta do repositório clonado
4. Navegue até o nível que desejar e adapte os exemplos conforme suas necessidades 😁
